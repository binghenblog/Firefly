# Microsoft 激活脚本 （MAS）

开源 Windows 和 Office 激活器，具有 HWID、Ohook、TSforge、KMS38 和在线 KMS 激活方法，以及高级故障排除。

------

### 如何激活 Windows / Office？[](https://massgrave.dev/#how-to-activate-windows--office)

#### 方法 1 - PowerShell（Windows 8 及更高版本） 

信息

1. **打开 PowerShell**
   为此，请按 Windows 键 + X，然后选择 PowerShell 或终端。
2. **复制并粘贴下面的代码，然后按 Enter。**

```text
irm https://get.activated.win | iex
```

或者，您可以使用以下 （这将在将来弃用）：

```text
irm https://massgrave.dev/get | iex
```

1. 您将看到激活选项。
   按 [1] HWID 进行 Windows 激活。
   按 [2] Ohook for Office 激活。
2. 就这样

### 不工作 ❓

- 如果您无法使用 PowerShell **方法启动 MAS**，请参考上面的**方法 2**。
- 如果 MAS 启动但显示错误，请检查以蓝色突出显示的故障排除步骤并按照这些步骤作。
- 如果问题仍然存在，请随时[在此处](https://massgrave.dev/troubleshoot)与我们联系。

------

注意

- PowerShell 中的 IRM 命令从指定的 URL 下载脚本，然后 IEX 命令执行该脚本。
- 在执行命令之前，请始终仔细检查 URL，并在手动下载文件时验证来源是否可信。
- 请小心，因为有些人会通过更改 IRM 命令中的 URL 来传播伪装成 MAS 的恶意软件。

## 特征

- **HWID （数字许可证）**永久激活 Windows 的方法
- **奥胡克**永久激活 Office 的方法
- **TSforge** 公司永久激活 Windows/ESU/Office 的方法
- **KMS38** 系列激活 Windows 直到 2038 年的方法
- **在线 KMS**激活 Windows/Office 180 天的方法（续订任务终身）
- 高级激活疑难解答
- $OEM$ 个用于预激活的文件夹
- 更改 Windows 版本
- 更改 Office 版本
- 检查 Windows/Office 激活状态
- 提供 All In One 和 Separate Files 版本
- 完全开源且基于批处理脚本
- 更少的防病毒检测

## 激活摘要

| 激活类型     | 支持的产品             | 激活期                         | 需要互联网吗？ |
| :----------- | :--------------------- | :----------------------------- | :------------- |
| 硬件         | Windows 10-11系统      | 永久                           | 是的           |
| 奥胡克       | 办公室                 | 永久                           | 不             |
| TSforge 公司 | Windows / ESU / Office | 永久                           | 不             |
| KMS38 系列   | Windows 10-11 服务器   | 直到 2038 年                   | 不             |
| 在线 KMS     | Windows / 办公软件     | 180 天。具有续订任务的生命周期 | 是的           |
